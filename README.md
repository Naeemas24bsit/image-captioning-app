AI Image Caption Generator

An AI-powered Image Captioning Application built using Deep Learning and Transfer Learning.

Project Overview

This application uses a fine-tuned BLIP (Bootstrapping Language-Image Pre-training) model to automatically generate natural language descriptions of uploaded images.

Model

- Architecture: BLIP
- Pretrained Model: Salesforce/blip-image-captioning-base
- Fine-tuned Dataset: Flickr8k
- Hosted on: Hugging Face

Technologies

- Python
- PyTorch
- Hugging Face Transformers
- Streamlit
- PIL

How to Use

1. Open the application.
2. Upload an image.
3. Click Generate Caption.
4. View the AI-generated description.
